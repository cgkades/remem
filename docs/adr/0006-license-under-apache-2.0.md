# ADR 0006: License Under Apache-2.0

- Status: Accepted
- Date: 2026-09-01

## Context

Remem is intended for broad use in personal and commercial developer tooling and may receive
contributions involving provider integrations. A clear patent grant is valuable for an
infrastructure project.

## Decision

License original Remem code and documentation under the Apache License 2.0.

## Consequences

- Users receive permissive copyright and patent grants.
- Redistributions must preserve the license and required notices.
- Contributions are made under Apache-2.0 unless explicitly stated otherwise.
- Compatible prior-art ideas may inform the design, but third-party code is not copied without a
  separate license review.
