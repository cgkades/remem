# Optional offline model proposals

Model learning is disabled by default. It requires enabled canonical evidence admission, enabled capture, an explicit primary managed PostgreSQL provider and `learningModel.enabled: true` with an absolute normalized `learningModel.modelPath`. There is no hosted-generation endpoint or fallback. OpenCode v2 and Pi can supply completed canonical evidence; OpenCode v1 retains its existing supported user-capture behavior and does not invent missing native evidence capabilities.

Run `npm run build`, then explicitly prepare pinned public assets with `REMEM_GENERATION_CACHE=/absolute/cache node scripts/prepare-local-model.mjs`. The output gives the directory to configure. This preparatory download sends no private memory to a model service. Runtime generation uses only existing local files with remote loading prohibited, q4 CPU inference and a separate worker. The worker hashes all bounded model files, rejects symlinks and records a SHA-256 asset identity; it cannot share mutable embedding-loader settings. Models require substantial CPU/RAM and disk space. Missing, changed or unsupported assets fail closed for model proposals while deterministic learning continues.

Each request contains at most eight current-session admitted user/tool events and 8,000 serialized input bytes. It excludes generated, retrieved, extension and foreign sources. The queue holds at most four session contexts, and output contains at most three strictly parsed proposals, each at most 600 characters with explicit numeric source IDs. Defaults allow 120 generated tokens and a 15-second deadline (configurable within 100ms–30s and 16–256 output tokens). Cancellation/deadlines terminate the inference worker. Shutdown drains within the same configured deadline and then terminates it. No raw model output or evidence body is logged on failure.

The model proposes quotations and numeric source IDs in a strict JSON response. A conservative deterministic significance gate first removes non-durable source text; this is a bounded extraction assistant, not unconstrained causal reasoning. Sources longer than 600 characters currently require deterministic reduction before model selection and are omitted by this selector. The model supplies no confidence; the review candidate uses a fixed score of 0.5, not a probability. The PostgreSQL transaction re-reads canonical evidence, reconstructs the full proposed body and provenance, checks scope/retention/admission, and records the independently computed outcome. Exact quotations require explicit review even if model confidence is one or automatic user learning is enabled. Non-extractive causal conclusions remain episodic-only; unsafe or malformed proposals are rejected. Model confidence is an annotation, never authorization. Deterministically supported user assertions keep their existing path and are not duplicated as model review copies. Existing current-state conflict, forget and promotion safeguards still apply; source loss prevents promotion.

This establishes an optional proposal assistant, not general autonomous causal inference. A reviewed source quotation can later be recalled with generated-source attribution; unreviewed or unsupported model claims cannot become current semantic truth. Historical tool evidence remains explicitly historical. Actual inference/evaluation artifacts are required to substantiate model behavior; mocked unit tests and green CI alone do not measure model quality.
